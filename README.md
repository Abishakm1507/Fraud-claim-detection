# Intelligent Healthcare Fraud Detection & Investigation Platform

An end-to-end platform for detecting, explaining, and investigating healthcare provider fraud using machine learning, SHAP explainability, multi-agent investigation, and a Retrieval-Augmented Generation (RAG) chatbot.

## Overview

This project combines a trained ML fraud-detection model with an explainability pipeline (SHAP + Gemini), a multi-agent investigation workflow (CrewAI), and a RAG-based chatbot to help analysts identify and investigate potentially fraudulent healthcare providers.

## Features

- **Fraud Score Prediction** – Logistic Regression model predicts provider-level fraud probability with risk-level classification (Low / Medium / High).
- **Explainability** – SHAP-based feature contributions, waterfall/summary plots, and natural-language explanations generated by Gemini.
- **Multi-Agent Investigation** – CrewAI-based agents (Coordinator, Claim Analysis, Provider Analysis, Beneficiary Analysis) collaborate to produce structured investigation reports.
- **RAG Chatbot** – LangChain + FAISS + Gemini-powered assistant that answers questions about providers, claims, and fraud patterns.
- **Report Generation** – Structured Markdown/JSON investigation reports with evidence fusion and confidence scoring.
- **Authentication** – JWT-based signup/login with bcrypt password hashing.
- **Interactive Dashboard** – React frontend with charts, provider search, investigation summaries, and PDF report export.

## Installation

### Prerequisites

- Python 3.10+
- Node.js 18+
- Google Gemini API key (for explainability and RAG)

### 1. Clone the repository

```bash
git clone https://github.com/Abishakm1507/Fraud-claim-detection.git
cd Fraud-claim-detection
```

### 2. Install Python dependencies

```bash
pip install -r requirements.txt
pip install -r backend/requirements.txt
pip install -r rag/requirements.txt
```

### 3. Install frontend dependencies

```bash
cd frontend
npm install
cd ..
```

### 4. Set up environment variables

Create a `.env` file in the project root:

```
GEMINI_API_KEY=your_gemini_api_key
```

## Running Backend

```bash
uvicorn backend.main:app --reload --port 8000
```

The API will be available at `http://127.0.0.1:8000`.

## Running Frontend

```bash
cd frontend
npm run dev
```

The app will be available at `http://localhost:5173`.

## Running RAG

```bash
cd rag
uvicorn main:app --reload --port 5000
```

The RAG chatbot API will be available at `http://127.0.0.1:5000`.

> **Note:** The frontend chatbot (`/chat` page) connects to the RAG service on port 5000. The backend `/chat` endpoint (port 8000) also wraps the RAG pipeline for in-app use.

## Environment Variables

| Variable | Description | Required |
|----------|-------------|----------|
| `GEMINI_API_KEY` | Google Gemini API key for explainability and RAG | Yes |

## API Endpoints

### Backend (port 8000)

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/auth/signup` | Register a new user (returns JWT) |
| POST | `/auth/login` | Login (returns JWT) |
| POST | `/predict` | Predict fraud score for a provider |
| GET | `/explain/{provider_id}` | Full explainability report (SHAP + Gemini + plots) |
| POST | `/investigate` | Run multi-agent investigation for a provider |
| POST | `/chat` | RAG chatbot response (wraps RAG pipeline) |
| GET | `/` | Health check |
| GET | `/test-key` | Check Gemini API key presence |

### RAG Service (port 5000)

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Health check |
| GET | `/health` | Health status |
| POST | `/chat` | Get chatbot answer |
| POST | `/chat-stream` | Stream chatbot answer |
